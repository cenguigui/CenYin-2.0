# 笒音2.0 下载线路

当前版本：**2.0.0**，支持 Android 7.0 及以上。大多数手机先选择 **ARM64**；老款 32 位手机选择 ARMv7，x86_64 用于对应架构的模拟器。

以下为用户提供的 GH-Proxy 公共加速入口。建议先尝试 IPv4 优选，无法连接时切换主站、双栈或其他节点。它们属于第三方服务，可用性受地区、运营商、网络类型和浏览器影响，不承诺所有网络均可用。
