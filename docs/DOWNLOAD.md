# 笒音2.0 下载线路

当前版本：**2.0.1**，支持 Android 7.0 及以上。大多数手机先选择 **ARM64**；老款 32 位手机选择 ARMv7，x86_64 用于对应架构的模拟器。

以下为用户提供的 GH-Proxy 公共加速入口。建议先尝试 IPv4 优选，无法连接时切换主站、双栈或其他节点。它们属于第三方服务，可用性受地区、运营商、网络类型和浏览器影响，不承诺所有网络均可用。

## 安装包校验

2026-10-18 更新为 2.0.1（构建 10）。公开与私有 Releases 提供相同的三种架构 APK，并核对上传后的 SHA-256。下载后可对照 [SHA256SUMS.txt](../SHA256SUMS.txt) 校验完整文件。

加速线路沿用用户提供的 GH-Proxy 节点；此前版本曾检查这些线路，本次不将旧版线路测试结果当作新版下载成功的证明。无法连接时请切换节点或 GitHub 原始下载。

应用源码继续保存在私有仓库，本公开仓库只有说明与演示资料。
