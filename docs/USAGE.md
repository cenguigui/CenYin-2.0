# 笒音2.0 使用说明

## 开始使用

1. 从项目首页或 Releases 下载适合设备的 APK，大多数手机使用 ARM64。
2. 安装并打开应用，在线搜索和播放需要网络。
3. 需要后台播放与锁屏控制时，按中文提示开启通知权限。桌面歌词需要额外开启悬浮窗权限。

## 播放与歌词

- 点击歌曲开始播放，底部迷你播放条展示当前歌曲；点击播放条进入完整播放器。
- 封面与歌词之间可左右滑动；歌词会随播放定位，滚动歌词可查看其他段落。
- 点击循环图标依次切换列表循环、单曲循环、随机播放，提示会直接显示在页面中。
- 点击进度条附近的音质文字查看可用音质、格式和文件大小；缺少大小的数据会明确提示。
- 右上角分享按钮分享当前播放歌曲，可复制内容或使用 Android 系统分享。
- 底部更多菜单可进入播放器样式、音质等设置。

## 主题与播放器

打开左上角菜单或“我的”中的装扮中心，选择主题皮肤、头像挂件或播放器样式。进入主题详情后等待资源准备，先查看实际首页和播放效果，再确认使用。

部分主题资源按需下载并缓存在本机。主题会影响底部导航、菜单和页面控件；开启夜间模式后，页面配色统一改为暗色。声音实验室中可以调整均衡器和高级音效。

## 本地歌单

在“我的 → 我的歌单”点击新增，填写名称即可创建。可以添加当前歌曲、重命名、调整顺序或移除歌曲。歌单保存在本机，不要求登录账号或配置后端。

分享或导出：打开歌单菜单，选择复制分享内容、系统分享或导出歌单文件。文件记录歌曲信息，不包含音频文件。

导入：选择歌单导入，粘贴公开歌单链接、分享内容，或选择支持的歌单文件。确认预览后可新建歌单，或合并到已有歌单，重复曲目会自动跳过。

支持的分享示例：

- 酷我电脑端：`https://www.kuwo.cn/playlist_detail/歌单编号`
- 酷我手机端：`https://m.kuwo.cn/newh5app/playlist_detail/歌单编号`
- 网易云公开歌单、笒音导出文件、TXT/M3U 清单。

公开平台可能限制可返回内容；导入页会显示实际获取的数量。跨平台曲目可能存在翻唱、现场等多个版本，请在预览时核对。

## 更新、备份和常见问题

- **保留资料更新**：下载相同架构的新版本，直接覆盖安装。
- **更换设备或卸载**：提前导出本地歌单。卸载或清除应用数据会移除本地资料。
- **安装包较大**：本版本带有离线播放器样式与视觉资源；主题完整资源仍按需下载。
- **加速下载失败**：切换另一条加速线路，或使用 GitHub 原始下载。
- **设备兼容性**：最低 Android 7.0；已经完成的原生验收环境为 Android 15 模拟器，其他设备如遇问题可提交 Issues。

## 校验安装包

将下载文件的 SHA-256 与项目根目录的 `SHA256SUMS.txt` 对照。Windows 可在 PowerShell 执行 `Get-FileHash -Algorithm SHA256 文件路径`；macOS/Linux 可使用系统的 SHA-256 校验工具。
