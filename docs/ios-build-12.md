# iOS 2.0.1 · 构建 12

2026-10-19 · iOS 15.0 及以上 · arm64 真机 Release · 未签名。

- 修复播放器展开、收起时底下首页横移、右侧露出黑块的问题。
- 下拉跟手，取消后回弹，收起从手指位置继续；系统中断长下拉时不再误关闭。封面与歌词左右滑动，内容页支持 iOS 侧滑返回。
- iOS 不再创建 Android 专用音效，修复播放初始化失败及歌词不显示；加密高音质使用 Dart 解密回退。
- 皮肤 APK 资源支持跨平台读取，复查“再生”主题及 10 个原生视频素材。
- 复查全部 19 款播放器样式；冬夜星辰、阴阳师保持封面原位置，将背景装饰上移对齐。

## 验证

静态分析通过；237 项单元/组件测试通过，1 项历史素材来源审计因缺少外部 Windows 原始缓存失败；新增及修改的手势测试全部通过。
iPhone 17 Pro / iOS 26.5 模拟器检查真实在线播放、歌词、拖动进度、加密音源、APK 皮肤导入、视频与播放器手势。模拟器检查不代表真机帧率、发热或电耗已验收。
