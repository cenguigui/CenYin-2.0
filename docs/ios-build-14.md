# iOS 2.0.1 · 构建 14

2026-10-19 · iOS 15.0 及以上 · arm64 真机 Release · 未签名。

## 本次修复

修复“下载管理”中的 FLAC 本地播放失败。旧版音频标签库写入封面时会生成无效的 FLAC 元数据结束标记，导致 iOS 返回原生解码错误。将 `audio_metadata_reader` 精确锁定到修复该问题的 1.8.1，保留音频帧和索引；其他依赖版本保持不变。本地文件失败时显示文件或格式提示，不再误报检查网络。

**旧版已写坏的 FLAC 文件需重新下载一次。** 更新应用不会改写现有音频；请在下载管理中重新下载失败的歌曲。新增 MP3、FLAC 的中文路径下载、播放和跳转进度回归测试。

修复动态播放器与视频皮肤启用 `mixWithOthers`、改变全局 iOS 音频会话的问题。音乐使用非混音的 Playback 会话；静音装饰视频不再将音乐变成次要音频。Android 保留原有混音和焦点处理。

启动时明确配置音乐音频会话；系统媒体信息同时提供歌曲名、歌手、封面、时长和播放进度。保留已有暂停、继续、上一首、下一首及进度控制通道。

继续保留构建 12 的播放与歌词、APK 皮肤导入、圆环对齐、iOS 转场黑边和下拉手势修复。

## 验证范围

- 原生修复前检查：播放时 `mixWithOthers=false`，打开动态播放器后变成 `true`，已复现会话被覆盖。
- 修复后检查 19 款播放器：非混音 Playback 会话保持；系统 Now Playing 中歌名、歌手、封面、时长、播放状态正确。
- 通过原生 audio_service 系统命令入站通道检查暂停、继续、跳转进度；检查暂停后的系统媒体状态。
- 模拟器手动切到主屏后音乐继续，返回应用进度持续推进。
- 用户反馈的《别让爱凋落 (卡点节奏版)》：实际下载 MP3 和 FLAC 后，iOS 原生本地播放、进度推进与跳转均通过。
- FLAC 标签回归检查：音频帧、STREAMINFO、索引不变，最后元数据块标记有效；本地错误提示回归通过。
- 静态分析通过；239 项单元与组件测试通过。1 项历史素材来源审计因缺少外部 Windows 原始缓存失败。

**灵动岛、控制中心及锁屏卡片在真机上的可见性和点击行为尚未完成真机验收。** 本次验证为原生媒体状态和命令通道，不能等同于真机系统界面显示已通过。播放期间在支持灵动岛的 iPhone 上，应由系统展示 Now Playing；本次未添加自定义实时活动或歌词小组件。
